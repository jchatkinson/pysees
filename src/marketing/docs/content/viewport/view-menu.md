The **View** menu holds checkbox items. Defaults are in brackets.

| Item | Shows |
|---|---|
| Node IDs (off), Element IDs (off) | Labels |
| Nodes (on), Elements (on) | The model geometry |
| Supports (on) | Restraint symbols |
| Nodal Loads (on), Element Loads (on) | Applied loads |
| Load Values (off) | Numeric load magnitudes |
| Load Patterns | A submenu to show or hide each pattern (only when patterns exist) |
| Grid (on) | The reference floor grid |
| Grids (on), Levels (on) | Your [grids and levels](/docs/model/grids-levels) |
| Zoom In, Zoom Out, Zoom To Fit | Camera |

View settings are saved with the project.
