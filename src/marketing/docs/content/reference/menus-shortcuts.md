| Tab | Holds |
|---|---|
| File | New (asks first; clears model, history and results), Open and Save a [project](/docs/files/save-open-projects), Import a .tcl / .py script, Export .tcl |
| Model | Undo / Redo, [drawing tools](/docs/model/drawing-tools), [views](/docs/viewport/views), selection, Define: [Grids & levels](/docs/model/grids-levels), [Underlays](/docs/viewport/underlays), [Units](/docs/viewport/units) |

| Results | Result type, playback, reactions, values, the [Display panel](/docs/results/display-panel) and [plots](/docs/results/plots) |

## Keyboard

| Keys | Action |
|---|---|
| <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>Z</kbd> | Undo |
| <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>Y</kbd> or <kbd>Shift</kbd> + <kbd>Z</kbd> | Redo |
| <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>A</kbd> | Select all |
| <kbd>Delete</kbd> | Delete the selection |
| <kbd>Esc</kbd> | Clear the selection; end a drawing chain; stop flying |
| <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>K</kbd> | Command palette (in Studio); search these docs (on the docs site) |
| <kbd>F</kbd> | Fit the view |
| <kbd>Shift</kbd> + <kbd>F</kbd> | [Fly mode](/docs/viewport/views#fly-mode) on or off |
| <kbd>Page Up</kbd> / <kbd>Page Down</kbd> | Story above / below, or next / previous grid |
| <kbd>Shift</kbd> + click | Add or remove an object from the selection |
| <kbd>Shift</kbd> while drawing | Lock the member to an axis |
| Type a length, <kbd>Enter</kbd> | Place the next point that far (Frame and Stud wall tools) |

Shortcuts are ignored while you type in a field.
