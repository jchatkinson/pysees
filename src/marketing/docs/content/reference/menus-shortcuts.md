| Menu | Item | Does |
|---|---|---|
| File | New Model | Starts over (asks first; clears model, history and results) |
| File | Open .py… | Opens a [saved project](/docs/files/save-open-projects) |
| File | Save .py… | Downloads the project |
| File | Import .tcl / .py… | Reads a script into a new model |
| File | Export .tcl | Downloads a Tcl script |
| Edit | Undo, Redo | See [Undo and redo](/docs/model/undo-redo) |
| Edit | Grids & Levels… | [Grids and levels](/docs/model/grids-levels) |
| Edit | Units… | [Units](/docs/viewport/units) |
| View | (checkboxes) | [View menu](/docs/viewport/view-menu) |

## Keyboard

| Keys | Action |
|---|---|
| <kbd>Esc</kbd> | Close the delete dialog, deselect |
| <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>K</kbd> | Search these docs |
| <kbd>Shift</kbd> + click | Add or remove a node from the selection |
