The **Results** tab on the right panel lists recorded data.

Result types: joint displacements, velocities and relative accelerations; element forces; shell stress resultants; reactions; and for modal cases, periods and frequencies, participating mass ratios and mode shapes.

## Controls

- A result-type select and a case filter.
- A global text filter, plus sort and filter menus on each column header.
- A threshold below which values show as 0.
- **Refresh** to reload the data.

Tables say "run an analysis first" until results exist.
