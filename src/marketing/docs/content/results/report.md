The **Report** tab of the left panel lists saved plots. They store the configuration, not the data, so they re-plot against whatever run is current.

- Click a plot to apply it.
- Double-click, or use the pencil icon, to rename. The trash icon deletes.
- An **update** link appears when the open plot differs from the saved one.
- A warning icon means some series have no data in the current run.

Saved plots are stored in the [project file](/docs/files/save-open-projects).
