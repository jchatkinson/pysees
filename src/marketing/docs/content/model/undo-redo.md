---
title: Undo and redo
description: Step back through model edits and analysis edits.
order: 15
keywords: undo redo history snapshot
---

Use **Edit > Undo** and **Redo**, or the arrow buttons in the top bar and the Model panel header. Model edits are kept as snapshots. The analysis list has its own undo position, and the saved project records analysis up to that position.

> [!NOTE]
> Editing the model or the analysis discards any stored results, because they would no longer match. Run the analysis again.

There are no keyboard shortcuts for undo and redo yet.
