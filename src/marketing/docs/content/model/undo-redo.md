---
title: Undo and redo
description: Step back through model edits and analysis edits.
order: 15
keywords: undo redo history snapshot
---

Use **Undo** and **Redo** on the Model or Edit tab, <kbd>Ctrl</kbd>/<kbd>⌘</kbd>+<kbd>Z</kbd> and <kbd>Ctrl</kbd>/<kbd>⌘</kbd>+<kbd>Y</kbd> (or <kbd>Shift</kbd>+<kbd>Z</kbd>), or the arrow buttons in the Model panel header. They act on the model while the Model panel is open, and on the analysis list while the Analysis panel is open. Each drawing or edit operation is one step. Model edits are kept as snapshots. The analysis list has its own undo position, and the saved project records analysis up to that position.

> [!NOTE]
> Editing the model or the analysis discards any stored results, because they would no longer match. Run the analysis again.
