The Model panel lists entities in collapsible groups with counts. **Expand all** and **Collapse all** are in the header, along with undo and redo. Clicking a row selects the entity and opens its form. Selecting something in the viewport opens its group and scrolls to the row.

| Group | Holds |
|---|---|
| Nodes | Node coordinates |
| Masses | [Nodal masses](/docs/model/nodes-masses) |
| Materials | [Uniaxial and nD materials](/docs/model/materials) |
| Sections | [Fiber and other sections](/docs/model/section-editor). Fiber sections open the section editor |
| Elements | [Elements](/docs/model/elements) |
| Transforms | [Geometric transformations](/docs/model/transformations) |
| Beam Integrations | [Integration rules](/docs/model/beam-integrations) |
| Constraints (fix) | [Supports](/docs/model/supports) |
| MP Constraints | [Multi-point constraints](/docs/model/mp-constraints) |
| Regions | [Regions](/docs/model/regions) |
| Time Series | [Time series](/docs/model/time-series) |
| Load Patterns | [Patterns and loads](/docs/model/load-patterns) |
| Other | Commands that have no editor yet. They show a message and a Delete button |
